# Introduction to AsyncIO

Asynchronous programming in Python allows your application to handle multiple I/O tasks (like network requests or file reads) without blocking the main execution thread.

## 1. Defining an Async Function

In modern Python (3.7+), async functions are declared using the `async def` syntax:

```python
import asyncio

async def fetch_data(task_id, delay):
    print(f"Task {task_id} starting...")
    await asyncio.sleep(delay)
    print(f"Task {task_id} completed!")
    return f"Result {task_id}"

async def main():
    result = await fetch_data(1, 2)
    print(result)

if __name__ == "__main__":
    asyncio.run(main())
```

## 2. Running Tasks Concurrently

To run multiple async tasks simultaneously, use `asyncio.gather()`:

```python
async def main():
    results = await asyncio.gather(
        fetch_data(1, 2),
        fetch_data(2, 3),
        fetch_data(3, 1)
    )
    print("All tasks finished:", results)
```

## Summary
AsyncIO is ideal for I/O-bound operations such as web scraping, API calls, and chat applications.
