For example:

```c
#include <stdio.h>
int main()
{
     int *p, s[10]; /* here by default all elements in array s are 0*/
     s[5] = 17; /* set 5th element to 17 */
     p = s; /* setting first element address to p */
     printf("%d", *(p + 5)); /* prints 17 */
     getchar();
}
```

```c
#include <stdio.h>
#define ARR_SIZE 10
int main()
{
     int s[ARR_SIZE], *p;
     int i;
     for (i = 0; i < ARR_SIZE; i++)
           s[i] = i*i;  /*storing squares of numbers 0-9 to array */

     p = s; /*setting address of first element of array s in pointer p.*/

     /*now printing all element of array by using pointer p. */
     for (i = 0; i < ARR_SIZE; i++)
           printf(" %d", *(p + i)); /* accessing ith element of array using *(p+i) */
     getchar();
     return 0;
}
```

**Arrays of Pointers:**

Pointers can be taken into an array like any other data type. The declaration for an int pointer array of size 100 is

```c
int *x[100];
```

To assign the address of an integer variable called var to the fifth element of the pointer array, we write

```c
x[4] = &var;
```

To find the value of var, we write

```c
*x[4]
```

If we want to pass an array of pointers into a function, we can use the same method that we use to pass other arrays.

Example:

```c
void display_array(int *q[])
{
     int t;
     for (t = 0; t<10; t++)
           printf("%d ", *q[t]);
}
```

Here, q is not a pointer to integers, it`s a pointer to an array of pointers to integers.
