1. 1.** C++** was invented by Bjarne Stroustrup in 1980 at AT&amp;T lab while adding Object-oriented constructs to the **C **language.
2. 2. **C++** is a General purpose OOP (Object –Oriented Programming) language.
3. 3. **C++** is a middle-level language, because it has both high and low level language features.
4. 4.** C++** is a best programming language for computer hardware interaction, a lot of control hardware, memory management, better performance etc.
5. 5.** C++** was initially called as “**C **with classes”, so we can say **C++** is an expanded version (new version) of C.
6. 6. Every **C **program can be compiled as **C++** but not every **C++** code is a **C **program.
7. 7.** C++** supports both procedural and OOP concept, so it can also called as hybrid programming language.

<!--[endif]-->The Object-Oriented Approach has following features or properties

- I.   Abstraction
- II.  Encapsulation
- III. Polymorphism
- IV. Inheritance
