Syntax:

| Exp1 ? Exp2 : Exp3 |
| :--- |

and equivalent to

| if (Exp1) Exp2; else Exp3; |
| :--- |

Here Exp1 is evaluated &amp; If it is true, Exp2 is evaluated and becomes the value of the entire ? expression. If Exp1 is false, then Exp3 is evaluated and its value becomes the value of the entire ? expression.

Examples:

```c
// sign function
int sign(int x)
{
    int result;
    result = x ? (x > 0 ? 1 : -1) : 0;
    return result;
}

// or also we can do it simply by
int sign(int x)
{
    return x ? (x > 0 ? 1 : -1) : 0;
}
```

```c
// factorial function
#include <stdio.h>

{
```
