**1) Function Declaration:**

The general form of a function declaration is

ret_type function_name(parameter_list);

For Example:

int AddThreeNumber(int number1, int number2, int number3);

**2) Function Definition:**

The general form of a function definition is

ret_type function_name(parameter_list)

{

body of the function

}

For Example:

```c
int AddThreeNumber(int number1, int number2, int number3)
{
     return (number1 + number2 + number3);
}
```

The ret_type specifies the type of data that the function returns.

(In the above example, addition of three integers is also an integer. So we can return their sum.)

[Note: A function may return any type of data except an array.]

The parameter_list is a comma-separated list of variable names and their associated types.

In the above example the comma-separated list of variable names and their associated types is (int number1, int number2, int number3)

The parameters receive the values of the arguments when the function is called.

For example if we call the above function for sum of values 100, 200, 300 we will write

int sum = AddThreeNumber(100, 200, 300);

A function can be without parameters, in which case the parameter list is empty.

For example:

int main() { return 0; }

An empty parameter list can be explicitly specified as such by placing the keyword void inside the parentheses.

Like

int main(void) { return 0; }

The parameter declaration list for a function takes this general form:

ret_type func_name(type varname1, type varname2, . . . , type varnameN)

**Scope of a Function:**

A function defines a block scope. A function`s code is private to that function and cannot be accessed by any statement in any other function except through a calling to the function. (For eample, we cannot use goto to jump into the middle of another function).

The code and data defined within one function cannot interact with the code or data defined in another function because the two functions have different scopes.

Variables that are defined within a function are local variables. A local variable comes into existence when the function is called and is destroyed when the function is exited.

Thus, a local variable cannot hold its value between function calls.

The only exception to this rule is when the variable is declared with the static storage class specifier. This causes the compiler to take the variable as if it were a global variable for storage purposes, but limit its scope to the function.

The formal parameters to a function also fall within the function`s block scope. A parameter can be accessed throughout the entire function. A parameter comes into existence when the function is called and is destroyed when the function is exited.

**In C/C++, All functions have file scope. Thus, we cannot define a function within a function. **

**Function Arguments:**

When we call the function we must pass the arguments of the function. Function parameters perform the special task of receiving the value of the arguments passed to the function. They also behave like any other local variable.

**Call by Value and Call by Reference:**

**Call by value-** This method copies the value of an argument into the formal parameter of the subroutine. So, changes made to the parameter have no effect on the argument.

**Call by Reference-** In this method, the address of an argument is copied into the parameter. Inside the subroutine, the address is used to access the actual argument used in the call. This means that changes made to the parameter affect the argument.

Examples: Here we take an example swapping values between two variables:

```c
/* Call by value example */
#include <stdio.h>
void swap(int a, int b) /* a and b are formal parameter */
{
     int temp = a;
     a = b;
     b = temp;
     printf("\n formal parameters are a = %d, b = %d", a, b);
}

int main()
{
     int a = 10, b = 20; /* a and b are arguments */
     printf("\n Argument are a = %d, b = %d", a, b);
     /* now passing arguments in the function */
     swap(a, b);
     printf("\n Argument are a = %d, b = %d", a, b);
     getchar();
     return 0;
}
```

<strong> </strong>

```c
/* Call by reference example */
#include <stdio.h>
void swap(int *a, int *b) /* a and b are formal parameter */
{
     int temp = *a;
     *a = *b;
     *b = temp;
     printf("\n formal parameters are a = %d, b = %d", *a, *b);
}

int main()
{
     int a = 10, b = 20; /* a and b are arguments */
     printf("\n Argument are a = %d, b = %d", a, b);
     /* now passing arguments in the function */
     swap(&a, &b);
     printf("\n Argument are a = %d, b = %d", a, b);
     getchar();
     return 0;
}
```

**argc and argv— Arguments to main()-**

Sometimes it is useful to pass information into a program when we run it. Generally, we pass information into the main() function via command line arguments.

A command line argument is the information that follows the program`s name on the command line of the operating system.

Two special built-in arguments, argc and argv, are used to receive command line arguments.

The argc parameter holds the number of arguments (argument count) on the command line and is an integer.

It is always at least 1 because the name of the program qualifies as the first argument.

The argv parameter (argument value) is a pointer to an array of character pointers.

Each element in this array points to a command line argument.

All command line arguments are strings— any numbers will have to be converted by the program into the proper binary format, manually.

In many environments, each command line argument must be separated by a space or a tab. Commas, semicolons, and the like are not considered separators.

```c
/* Example: passing arguments in main function  */
#include <stdio.h>
#include <stdlib.h>
int main(int argc, char *argv[])
{
     if (argc != 2)
     {
           printf("your name not found...\n");
           exit(1);
     }
     printf("Hello %s", argv[1]);
     getchar();
     return 0;
}
```

```c
/* Countdown program. */
#include <stdio.h>
#include <stdlib.h>
#include <ctype.h>
#include <string.h>
int main(int argc, char *argv[])
{
     int disp, count;
     if (argc<2)
     {
           printf("You must enter the length of the count\n");
           printf("on the command line. Try again.\n");
           exit(1);
     }

     if (argc == 3 && !strcmp(argv[2], "display"))
           disp = 1;
     else
           disp = 0;

     for (count = atoi(argv[1]); count; --count)
           if (disp)
                printf("%d\n", count);

     putchar(`\a`); /* this will ring the bell */
     printf("Done");
     return 0;
}
```
