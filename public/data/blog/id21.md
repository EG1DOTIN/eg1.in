## Overview

The **N-Queens Problem** is the classic mathematical puzzle of placing $N$ chess queens on an $N \times N$ chessboard such that no two queens threaten each other. A queen can attack any piece in the same row, column, or diagonal.

Solutions exist for all natural numbers $N \ge 4$ (there are no solutions for $N = 2$ and $N = 3$).

## Backtracking Strategy

1. Start in the leftmost column.
2. If all queens are placed, output the board configuration.
3. For the current column, try placing a queen in each row.
4. Check if the queen is safe from previously placed queens (`isSafe`).
5. If safe, mark the cell and recursively place queens in the next column.
6. If placing the queen leads to no solution, remove the queen (backtrack) and try the next row.

## C++ Source Code

```cpp


#include <iostream>
#include <cstdio>
#include <cstdlib>
#include <conio.h>

const unsigned int N = 8;
using namespace std;

// Print N Queen chess problem solution
void PrintNQSolution(bool board[N][N])
{
     for (int i = 0; i < N; i++)
     {
           for (int j = 0; j < N; j++)
                cout << board[i][j] << "  ";
           cout << endl;
     }
}

/* check if a queen can be placed on the board[row][col]*/
bool CheckSafe(bool board[N][N], int row, int col)
{
     int i, j;
     for (i = 0; i < col; i++)
     {
           if (board[row][i])
                return false;
     }
     for (i = row, j = col; i >= 0 && j >= 0; i--, j--)
     {
           if (board[i][j])
                return false;
     }
     for (i = row, j = col; j >= 0 && i < N; i++, j--)
     {
           if (board[i][j])
                return false;
     }

     return true;
}

/*solve N Queen problem */
bool SolveNQ(bool board[N][N], int col)
{
     if (col >= N)
           return true;

     for (int i = 0; i < N; i++)
     {
           if (CheckSafe(board, i, col))
           {
                board[i][col] = true;
                if (SolveNQ(board, col + 1) == true)
                     return true;
                board[i][col] = false;
           }
     }

     return false;
}

/* solves the N Queen problem using Backtracking and print the solution.*/
bool SolveAndPrintNQ()
{
     bool board[N][N] = { 0 };
     if (SolveNQ(board, 0) == false)
     {
           cout << "Solution does not exist" << endl;
           return false;
     }
     PrintNQSolution(board);
     return true;
}

int main()
{
     cout << "**** " << N << " Queens Problem Solution *****\n\n";
     SolveAndPrintNQ();

     _getch();
     return 0;
}
```

## Complexity Analysis

The state space search tree explores potential board configurations, pruning invalid branches via safety checks. For $N = 8$, the algorithm efficiently discovers valid configurations within milliseconds.
