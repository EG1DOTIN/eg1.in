## Overview

In C, functions have physical entry points in memory. A **function pointer** stores the starting execution address of a function, allowing functions to be passed as callbacks or invoked dynamically at runtime.

## Function Pointer Syntax & Declaration

```c
return_type (*func_ptr)(param_types);
```

## Code Example

```c
#include <stdio.h>

void print(char* s, int(*p)(char*))
{
     (*p)(s);
}

int main(void)
{
     char s1[80];
     int(*p)(char *); /* function pointer */
     p = printf;     /* assign address of printf function to p */
     printf("Enter a strings:");
     gets(s1);
     print("\nYou entered:", p); /* pass address of printf via p */
     print(s1, p);   /* pass address of printf via p */
     getchar();
     return 0;
}
```

Output:

Enter a strings: www.eg1.in

You entered: www.eg1.in
