## Overview

Learning C is structured like learning a natural language:

1. In English, we start with **alphabets**, combine alphabets to construct **words**, assemble words into **sentences**, and organize sentences into **paragraphs**.
2. In C, we start with the **character set** (alphabets, digits, and special symbols), combine them into **tokens** (constants, variables, and keywords), assemble tokens into **instructions**, and organize instructions into a complete **program**.

## C Character Set

The table below lists the valid alphabets, numbers, and special symbols recognized by standard C compilers:

| Category | Allowed Characters |
| :--- | :--- |
| **Alphabets** | `A-Z`, `a-z` |
| **Digits** | `0-9` |
| **Special Symbols** | `~ ' ! @ # $ % ^ & * ( ) _ - + = | \ { } [ ] : ; " ' < > , . ? /` |

## Language Building Blocks

- **Character Set**: Foundational alphabets, digits, and symbols.
- **Constants, Variables & Keywords**: Named tokens holding values or reserving compiler actions.
- **Instructions / Statements**: Syntactic units that perform arithmetic, assignments, or control flow.
- **Program**: A collection of functions and instructions executed by the operating system.
