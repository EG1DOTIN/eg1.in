## Overview

The `while` loop repeatedly executes a target statement as long as a given condition remains true. It tests the condition before executing the loop body (entry-controlled loop).

## Syntax & Operation

```c
while (condition)
{
    statement;
}
```

## Practical Code Examples

```c
// printing in while loop

#include <stdio.h>

int main()
{
      int i = 0;

      while (i < 10)
      {
            printf("i = %d\n", i);
            i++;
      }

      getchar();
      return 0;
}
```

```c
// reverse direction with while

#include <stdio.h>

int main()
{
      int i = 10;

      while (i > 0)
      {
            printf("i = %d\n", i);
            i--;
      }

      getchar();
      return 0;
}
```

```c
//infinite while loop

#include <stdio.h>

int main()
{
      while(1) printf("this is an infinite loop\n");

      // it will never return here

      return 0;
}
```
