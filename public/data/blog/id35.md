## Overview

C is a general-purpose programming language developed at AT&T's Bell Laboratories in 1972 by Dennis Ritchie on a DEC PDP-11 minicomputer running UNIX.

C is widely considered a middle-level language because it combines the power, structured logic, and clarity of high-level languages with the low-level memory addressing and hardware control of assembly language. It serves as the bedrock for modern operating systems, virtual machines, database engines, and runtime systems.

## How C Works: The Compilation Pipeline

C source code undergoes a multi-stage compilation process before execution:

1. **Source Code (`.c`)**: Human-readable source text written by the developer.
2. **Preprocessor**: Processes directives like `#include` and `#define`.
3. **Compiler**: Translates C code into assembly or native machine object files (`.obj` / `.o`).
4. **Linker**: Combines object files with standard C runtime libraries into an executable binary (`.exe` / ELF).

> **Compiler vs. Interpreter**: Unlike an interpreter (which executes instructions line by line), a C compiler processes the whole program ahead of time, producing high-performance machine code.

## Hello World in C

```c
// A "Hello World" program using C language
#include <stdio.h>

int main(void)
{
    printf("hello world\n");

    getchar();
    return 0;
}
```

## Code Explanation

- `#include <stdio.h>`: Preprocessor directive including the Standard Input/Output library header containing prototypes for `printf()` and `getchar()`.
- `int main(void)`: Defines the primary entry point where execution begins.
- `printf("hello world\n")`: Emits the formatted string to the console stdout.
- `return 0`: Conveys exit status code '0' to the operating system, confirming successful program termination.
