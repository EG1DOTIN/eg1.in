## Overview

A **Magic Square** of order $N$ is an $N \times N$ grid of distinct positive integers from $1$ to $N^2$ such that the sum of numbers in each row, column, and main diagonal equals a constant value, known as the **Magic Constant** ($M$):

$$M = \frac{N(N^2 + 1)}{2}$$

For an order $N = 5$ magic square, $M = \frac{5(25 + 1)}{2} = 65$.

## Siamese Construction Method

For odd order magic squares ($N = 1, 3, 5, 7, \dots$), the Siamese method proceeds as follows:
1. Place number '1' in the middle column of the top row.
2. Move diagonally up and right (`row - 1`, `col + 1`), wrapping around edges.
3. If the destination cell is already occupied, drop down one row from the last placed number.

## C++ Source Code

```cpp


#include <stdio.h>
#include <iostream>

int main()
{
     //Define odd number for a Magic Square
     const int n = 5;
     //Take procedure only for odd number
     if (n % 2)
     {
           // Show Order and Magic Sum;
           std::cout << "Odd Number Magic Square: " << n << " x " << n << "\n";
           std::cout << "It's Magic Sum is: " << n*(n*n + 1) / 2 << "\n\n";
           //Take a 2d array
           int magic[n][n];
           int row = 0, col = n / 2, i, square = n * n;
           //Calc the elements
           for (i = 1; i <= square; i++)
           {
                magic[row][col] = i;
                if (i % n == 0) row++;
                else
                {
                     if (row == 0) row = n - 1;
                     else row--;
                     if (col == (n - 1))  col = 0;
                     else col++;
                }
           }

           //Show the result
           for (size_t i = 0; i < n; i++)
           {
                for (size_t j = 0; j < n; j++)
                     std::cout << magic[i][j] << "\t";
                std::cout << "\n";
           }
     }

     getchar();
     return 0;
}
```
