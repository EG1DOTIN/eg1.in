## Overview

A random password generator creates strong, unpredictable credentials to protect user accounts. High-entropy passwords combine uppercase letters, lowercase letters, numeric digits, and special characters.

## Password Generation Strategy

1. Seed the pseudo-random number generator with the current system time (`srand(time(NULL))`).
2. Define character pools for letters, digits, and symbols.
3. Select random characters from the pools up to the requested length.

## C Source Code

```c
#define _CRT_SECURE_NO_WARNINGS 1

#include <stdio.h>
#include <conio.h>
#include <stdlib.h>
#include <time.h>

int main()
{
     int counter = 0;
     srand(time(NULL));  // seeding function for random()
     char randChar;
     int  passwordLength;

     printf("****A Random Password Generator****\n\n");
     printf("Type password Length: ");
     scanf("%d", &passwordLength);
     printf("\n\n");

     while (counter < passwordLength)
     {
           //Get a random char among 70 characters
           randChar = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789@#$%^&*!"[rand() % 70];
           printf("%c", randChar);
           counter++;
     }
     printf("\n");

     return 0;
}
```


## Security Considerations

For standard applications, `rand()` combined with `time(NULL)` provides convenient pseudo-randomness. For high-security cryptographic requirements, operating-system-provided entropy sources (such as `/dev/urandom` on POSIX or `CryptGenRandom` / `BCryptGenRandom` on Windows) are recommended.
