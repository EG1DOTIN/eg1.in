## Overview

In C, **Identifiers** are names given to variables, functions, arrays, and labels. A **Variable** is a named storage location in memory whose value can be manipulated during program execution.

## Rules for C Identifiers

1. The first character must be an alphabet (`a-z`, `A-Z`) or an underscore ('_').
2. Subsequent characters may be alphabets, digits (`0-9`), or underscores.
3. Special symbols (such as `@`, '!', '#', '.', '$') are not permitted.
4. Identifiers are case-sensitive (`myVar` is distinct from `myvar`).
5. Keywords (like `int`, `while`, `return`) cannot be used as identifier names.

| Valid Identifiers | Invalid Identifiers | Reason for Invalidation |
| :--- | :--- | :--- |
| `i1` | `1i` | Cannot begin with a digit |
| `a23` | `23a` | Cannot begin with a digit |
| `My_num` | `My..num` | Periods are not allowed |
| `small_var` | `small!var` | Exclamation mark is not allowed |

## Declaring Variables

In C, variables must be declared with their data type before they are used:

```c
type variable_name;
```

**Examples:**

```c
int i, j, k;
short int si;
unsigned int ui;
double d, val;
```

## Variable Scopes and Types

1. **Local Variables**: Declared inside a function block and accessible only within that function.
2. **Formal Parameters**: Declared in a function parameter list to receive arguments passed to the function.
3. **Global Variables**: Declared outside of all functions, accessible by any function in the file.

## Code Example: Variable Scopes

```c
#include <stdio.h>

int count; /* count is global */

void func1(void);
void func2(int i, char c); /* i and c are formal parameters */

int main(void)
{
    count = 100;
    func1();
    return 0;
}

void func1(void)
{
    int temp; /* temp is local */
    temp = count;
    func2(5, 'a');
    printf("count is %d\n", count);
    /* will print 100 */
}

void func2(int i, char c)
{
    for (i = 1; i < 10; i++)
        putchar(c);
}
```
