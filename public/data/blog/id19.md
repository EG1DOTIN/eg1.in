## Overview

When developing console applications or login interfaces, displaying passwords in plaintext poses a security risk. In C, we can mask user keystrokes by capturing characters without echo using `_getch()` and printing an asterisk ('*') for each character entered.

## C Console Password Masking Implementation

```c
#include <stdio.h>
#include <conio.h>

int main()
{
     char password[20], ch = 0;
     int i = 0, j;
     printf("Enter the password <limit 20 characters>: ");
     while (i < 20)
     {
           ch = _getch();
           if (ch == '\r')
                break;
           password[i] = ch;
           i++;
           ch = '*';
           printf("%c", ch);
     }
     password[i] = '\0';

     printf("\nThe password is :");
     for (j = 0; j < i; j++)
     {
           printf("%c", password[j]);
     }
     return 0;
}
```


## How It Works

1. **`_getch()`**: Reads individual characters from the console without echoing them to the screen.
2. **Carriage Return Detection (`'\r'`)**: Pressing the Enter key sends `'\r'`, which breaks the input loop.
3. **Asterisk Output**: For every character captured, an asterisk ('*') is printed.
4. **Null Termination (`'\0'`)**: Explicitly appends `'\0'` to terminate the password string properly.
