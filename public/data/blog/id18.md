## Overview

In C, strings are null-terminated character arrays. Standard library functions like `strlen`, `strcpy`, `strcat`, and `strcmp` manipulate these strings. Implementing these functions from scratch provides deep insight into pointer traversal and memory management.

## Custom String Functions Implementation

```c


#define _CRT_SECURE_NO_WARNINGS

#include <stdio.h>
#include <stdlib.h>

/* string length */
int StrLength(char *string)
{
      char *count = string;
      while (*count)
      {
            count++;
      }

      return count - string;
}

/* string append */
char* StrAppend(char* string, char* append)
{
      char* newstring = NULL;
      size_t needed = _snprintf(NULL, 0, "%s%s", string, append);
      newstring = (char*)(malloc(needed));
      sprintf(newstring, "%s%s", string, append);

      return newstring;

/* string append char */
char* StrAppendChar(char* string, char append)

      char* newstring = NULL;

      sprintf(newstring, "%s%c", string, append);

      return newstring;
}

/* string equals */
int StrEquals(char *equal1, char *eqaul2)
{
      while (*equal1 == *eqaul2)
      {
            if (*equal1 == '\0' || *eqaul2 == '\0')
            {
                  break;
            }
            equal1++;
            eqaul2++;
      }

      if (*equal1 == '\0' && *eqaul2 == '\0')
      {
            return 0;
      }
      else
      {
            return -1;
      }
}

/* string replace */
char* StrReplace(char* search, char* replace, char* subject)
```

## Function Breakdown

- **`mystrlen`**: Increments a counter while advancing a pointer until encountering the null terminator (`'\0'`).
- **`mystrcpy`**: Copies characters from source to destination one by one including the final `'\0'`.
- **`mystrcat`**: Traverses to the end of destination string and appends characters from source string.
- **`mystrcmp`**: Compares character values sequentially and returns the difference.
