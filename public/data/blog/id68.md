## Overview

C++ introduces modern stream I/O facilities (`<iostream>`) such as `std::cin` and `std::cout`, type-safe formatting, and flexible local variable declarations anywhere within a block.

## C++ Stream I/O Basics

The line #include `<iostream>` includes the declarations of the standard

stream Input/Output facilities as found in `<iostream>`. The std:: specifies that the name cout is in the standard-library namespace (we will discuss namespace on following blog, just forget it for now).

## Square and Cube Calculator

The following code demonstrates streams (`cin` and `cout`), user input, and formatted output:

```cpp
// input a number from user and get square and qube of it

#include <iostream>
using namespace std; //now we can use direct cout, cin etc without specify std::

int main()
{
     cout << "\nInput any number: "; // cout <<  is used to print
     int number; // we can define any datatype anywhere in a funtion
     cin >> number; // cin >>  is used to scan or get input

     int square = number * number;

     cout << "\nSquare of the number is " << square;
     cout << "\ncube of the number is " << number * number * number;

     return 0;
}
```

## C++ Style Headers

 In C, we used `<stdio.h>` header file. We can also use it in C++, but that looks old, so a new style header is presented by C++ that is `<iostream>`. Here is not .h extension to name iostream, it’s not specific reason but it is a new style header file so it is without .h, so just ignore it, as we can make any file without extension and include it in our code in both C or C++. ## Flexible Variable Declarations

 On the above code we see that in C++ we can declare local variables any where into a function code, but in C, we cannot do that; we must have to declare all the local variables on just starting of the function block in C.
